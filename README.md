# Desafio Técnico — Desenvolvedor

Olá, avaliador! 👋

Este projeto foi desenvolvido como parte do desafio técnico para a vaga de **Desenvolvedor**.

Para a implementação, utilizei:

* **HTML5**
* **CSS3**
* **JavaScript**
* **Bootstrap 5**

O projeto contempla os desafios propostos, incluindo **cálculo de comissão, movimentação de estoque e cálculo de juros**, com validações e feedbacks para o usuário.

Apesar de meu foco profissional atualmente ser **PHP e desenvolvimento full stack**, aproveitei o desafio para demonstrar também minha experiência com desenvolvimento front-end, JavaScript e UI/UX.

Agradeço pela oportunidade de participar do processo seletivo. **Ficarei muito feliz em ter a oportunidade de conversar com vocês em uma entrevista e apresentar melhor minha experiência, meus conhecimentos e como posso contribuir com o time.**

Obrigado pela avaliação! 🚀
